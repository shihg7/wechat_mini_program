# 工具箱

一个完全离线的微信小程序日常工具箱。首页平级提供十个工具：日期计算、单位换算、二维码生成、截图打码、决策转盘、AA 分账、简版行程、通用清单、程序员生涯模拟和华子研发模拟；右上角仅保留帮助与数据设置。

当前应用版本为 `1.11.4`。应用不要求登录，也不依赖业务服务器。日期、换算、二维码和截图打码只存在当前页面，退出即清空；两个模拟器共用一套按域隔离的本地探索统计，只记录事件展示、回答次数和轮次，不记录答案内容、昵称或账号，不联网，也不进入备份；其余五类工具数据保存在微信小程序本地缓存中，彼此不保存关联 ID。

## 协作开发

开发者和编程 Agent 开始工作前必须阅读 [AGENT.md](./AGENT.md)。其中记录了产品边界、代码结构、数据约束、UI 底线、测试发布流程，以及[微信开发者工具官方 Skills](https://developers.weixin.qq.com/miniprogram/dev/devtools/Skills.html)的学习、导出和分场景使用方式。

项目统一使用微信官方导出的 `wechatide-skill` 完成编译、模拟点击、日志诊断、预览和体验版上传，不再使用非官方小程序调试桥接方案。每次代码变更都要检查并更新 README；帮助内容变化后还要重新生成 `docs/USER_GUIDE.md`。

## 十个工具

### 日期计算

- 支持日期间隔、日期推算和倒数日。
- 间隔结果同时显示相隔天数、含首尾天数及周数余数。
- 日期推算支持自然日，以及仅排除周六、周日的工作日。
- 统一使用 UTC 日序计算，覆盖闰年、跨月和跨年。
- 结果可复制，退出页面后不保存输入或历史。

### 单位换算

- 支持长度、面积、重量、体积、温度、时间、速度和数据容量。
- 支持交换来源与目标单位，并实时更新换算结果。
- 八类入口使用完整网格，长单位采用上下全宽选择器，不截断单位名称。
- 体积中的杯、品脱、加仑采用美制。
- 数据容量同时提供十进制 `KB/MB/GB` 与二进制 `KiB/MiB/GiB`。
- 不提供需要联网更新的汇率换算，退出页面后不保存输入。

### 二维码生成

- 支持普通文字、网址和 Wi-Fi 信息生成标准二维码。
- Wi-Fi 支持 WPA/WPA2、WEP、无密码和隐藏网络。
- Wi-Fi 安全类型、隐藏网络和密码使用全宽布局，避免窄屏裁切。
- 使用 `qrcode-generator@1.4.4` 的 MIT 许可源码在工具分包内离线编码。
- 固定 M 级纠错、四模块留白和高对比黑白样式，支持保存 `800 × 800` PNG。
- 输入限制为 `1000` 个 UTF-8 字节；退出页面后清除文字、SSID 和密码。
- 本功能不生成需要服务端接口的微信小程序码。

### 截图打码

- 从相册选择单张聊天截图，图片与编辑状态不上传、不写缓存、不进入备份。
- 使用保守的结构化规则尝试标记头像、群昵称和顶部标题；先定位聊天栏与底部输入工具栏，只在消息内容区域寻找候选。
- 头像必须同时满足边缘通道、至少三侧稳定方形边界和紧邻内侧的消息证据；远处气泡不能为无关的壁纸图块提供依据。
- 群昵称只在头像附近检测到稀疏文字形态时生成紧贴内容的候选；孤立的壁纸纹理边缘会从文字边界中剔除，普通私聊气泡和聊天图片不会自动扩成名称区域。
- 自动候选必须由用户检查，可手动框选、涂抹、移动、缩放、停用和重新启用。
- 支持马赛克、模糊、黑灰白纯色，以及最多 `30` 步撤销和重做；马赛克与模糊设有安全强度下限，避免调到几乎无效。
- 未选中区域时，效果、颜色和强度会应用到全部打码；点中某个边框后只调整所选区域。强度滑块拖动时实时预览，松手后合并为一次撤销操作。
- 多个区域重叠时按马赛克、模糊、纯色依次绘制，确保更彻底的纯色遮挡不会被较弱效果覆盖。
- 编辑画布支持平移和双指缩放，页面锁定高度，底部保存操作始终可见。
- 保存时在原始像素坐标重新绘制 PNG，不静默缩小超大长截图；设备无法保持原尺寸时明确提示。
- Canvas 重新编码会移除原图元数据，只有用户主动保存后结果才会进入系统相册。

### AA 分账

- 支持多账本、多成员，以及一笔支出由指定成员参与分摊。
- 支持人均、固定金额、百分比和份数四种分摊方式。
- 自动计算成员已付、应摊、净额与推荐转账方案。
- 支持部分结算、完整结算、撤销结算和结算历史。
- 每个账本使用单一币种，不会把不同币种静默相加或换算。
- 金额始终以整数最小货币单位保存，例如人民币 `10.01` 元保存为 `1001` 分，避免浮点误差和尾差丢失。
- 支持导出结算图片、私人 PDF、匿名 PDF 和账本明细 JSON。
- 账本内部数据版本保持 `schemaVersion: 4`。

### 简版行程

- 保存目的地、开始日期和结束日期。
- 按天添加时间、标题、地点和备注。
- 支持事项编辑、删除及同日上下排序。
- 阻止事项日期超出行程范围，并提示同一天的时间冲突。
- 只管理日程，不记录预算、个人支出或其他工具的关联关系。

### 通用清单

- 支持创建和维护多份独立清单。
- 清单项可新增、编辑、完成、删除和上下排序。
- 自动计算已完成数量与整体进度。
- 内置旅行打包模板，重复应用模板不会生成重复项目。
- 同样适用于采购、出门准备和普通待办。

### 决策转盘

- 支持保存多份转盘，并批量输入 `2-50` 个选项。
- 支持按钮旋转和手势拨动，使用惯性动画停在固定高对比指针下。
- 选项可排序、临时停用或移出本轮。
- 保存最近 `50` 条结果历史，可再次旋转或清空历史。

### 程序员生涯模拟

- 一次模拟约 `20-30` 分钟，依次经历入行求职、初级生存、独当一面、核心骨干、路线分叉和职业答案。
- 事件库扩展为 `360` 个职业情景、至少 `1075` 个选择；单次模拟仍经历 `36` 个抉择。
- 新支线覆盖 AI 协作、供应链安全、无障碍、隐私伦理、跨国远程、裁员、创业、家庭照护、开源治理、职场误会和虚构戏剧性反转等主题，事件卡会显示主题标签。
- 支持“自由模拟”和“今日情景”：自由模拟首轮每阶段安排 `4` 个主线和 `2` 个支线；复玩每阶段最多 `1` 个主线，其余 `5` 个位置优先安排符合当前经历且尚未遇见的事件。
- “今日情景”同一天保持固定题序，不受个人探索统计影响，便于比较不同选择。
- 技术力、沟通力、精力、积蓄和影响力五项属性限制在 `0-100`。
- 选择前仅提示影响方向，选择后显示即时变化；隐藏经历和延迟后果会影响后续事件及职业答案。
- 选项正文与影响标签分层展示，长文字不会被标签挤压或两行裁切，切换事件时底部操作区保持稳定。
- 职业画像会根据属性、隐藏经历和选择标签动态变化；结果页提示尚未结算的伏笔。
- 每章结束生成复盘，展示五项属性净变化、选择风格、关键转折和下一章预告。
- 每次选择立即自动存档，结果反馈与继续推进分成两个阶段，重复点击不会重复结算。
- 生涯档案保留最终属性、职业画像、关键词、关键选择和职业答案，可发现 `12` 种职业答案、`12` 项跨生涯里程碑，并显示 `360` 个事件的图鉴进度。
- 结果页和历史档案可复制纯文字生涯总结，便于与朋友比较同题选择。
- 事件池使用存档种子，确保相同种子与相同选择能够得到相同结果。
- 首页、档案和结果会显示发现进度、本轮新题数和新题率；探索统计只用于减少复玩重复，不包含用户选择内容。
- 本功能是基于预设职业情景和本地规则的互动模拟，不包含奖励、排名、抽奖或付费机制；结果仅用于选择反思，不构成职业建议。

### 华子研发模拟

- 定位为非官方的研发文化情景模拟，不使用企业商标图形，也不表示与华为存在授权、合作或背书关系。
- 词典包含 `48` 个公开语境词条，区分华为公开材料、华为云公开文档、公开管理资料、行业通用表达和网络职场叙事。
- 情景池包含 `192` 个虚构复合遭遇、`576` 个选择，覆盖入场对齐、版本攻坚、一线协同、路线抉择和绩效与去留五个阶段。
- 单次模拟按种子从每阶段抽取 `3` 个情景，共完成 `15` 次选择；最后三题固定来自绩效与去留阶段，同一种子可复现事件顺序。
- 首轮完成后解锁 `10` 个复玩专属情景，每个阶段各两个；第二轮会优先安排这些新支线。
- 后续抽题依次优先未见题、较少出现且不在最近记录中的题；题池容量允许时，前四次完整模拟不会重复，耗尽后再按出现次数和最近使用顺序调度。
- 绩效与去留覆盖 B 绩效、“B 里靠前”、AT 评议后改档、输出非研发、转岗后继续背旧活、当众斥责、绩效申诉和去留规划。
- 交付信用、技术深度、能量余量和组织影响四项数值始终限制在 `0-100`，选择反馈只结算一次。
- 结果提供 `8` 种研发画像、路线关键词、完整选择记录和可复制的文字总结。
- 黑话词典支持关键词与分类搜索，词条解释可复制。
- 选项卡采用自然高度和完整换行，不使用行数截断或省略号；页面锁定为内部滚动，切换反馈时不会带动整页抖动。
- 所有遭遇均为虚构创作，不对应具体真实员工或团队；二手报道只作为创作入口，并统一标记“网络职场叙事，非官方定义”。
- 本功能不要求昵称；当前选择、反馈、搜索词和结果仅存在页面内存，重新开始或离开页面后清空。
- 第二轮解锁复玩支线，并优先安排未见事件；题池逐渐耗尽后再按冷却期和低频顺序平衡重复。
- 本机共享探索统计只保存事件展示次数、回答次数、首次与最近出现轮次和最近运行摘要；不保存选择内容、结果、昵称或账号，也不进入备份。

## 本地数据

五类持久工具通过本地域 Store 读写数据，不直接操作业务缓存；日期、换算、二维码和截图打码没有 Store，也不进入备份：

| 工具 | Store | 缓存键 |
| --- | --- | --- |
| 简版行程 | `miniprogram/utils/tripStore.js` | `toolbox_trips` |
| 通用清单 | `miniprogram/utils/checklistStore.js` | `toolbox_checklists` |
| AA 分账 | `miniprogram/utils/tripLedgerStore.js` | `toolbox_ledgers` |
| 决策转盘 | `miniprogram/packages/tools/utils/wheelStore.js` | `toolbox_wheels` |
| 程序员生涯模拟 | `miniprogram/packages/tools/utils/careerGameStore.js` | `toolbox_career_runs` |

两个模拟器共用轻量探索统计 Store，并按 `career`、`huawei` 两个域隔离：

| 内容 | Store | 缓存键 |
| --- | --- | --- |
| 事件展示/回答次数、出现轮次和最近运行摘要 | `miniprogram/packages/tools/utils/simulationStatsStore.js` | `toolbox_simulation_stats` |

该 Store 不保存答案内容、反馈正文、昵称、账号或研发画像，不联网，也不属于备份 v3 的五类业务数据。数据设置中的“清空全部数据”会同时重置两个模拟器的探索统计。

### 完整备份

数据设置页可以导出和导入完整 JSON 备份。当前工具箱备份格式为 `schemaVersion: 3`，与 AA 账本自身的 `schemaVersion: 4`、生涯模拟存档自身的 `schemaVersion: 2` 是不同层级的版本号。

```js
{
  schemaVersion: 3,
  app: "local-toolbox-miniprogram",
  exportedAt: "...",
  trips: [],
  checklists: [],
  ledgers: [],
  wheels: [],
  careerRuns: []
}
```

- 导入前会校验应用标识、版本、集合类型和重复 ID。
- 兼容导入工具箱备份 v1、v2；v1 不包含生涯模拟数据，导入时按空生涯集合处理。
- 旧 v1、v2 备份中的 `records` 快评集合会被忽略，不影响其余五类数据恢复。
- 支持合并导入与覆盖导入。
- 写入前会为五个缓存创建统一快照；任一缓存写入失败时，已写入的集合会自动回滚。
- 合并时若出现多个活动生涯，只保留更新时间最新的一段为活动进度，其余标记为已中断。
- 数据设置页显示本地占用和上次成功导出时间，也提供清空全部工具数据的入口。

### 首次升级清理

第一次运行工具箱版本时，`toolboxMigration` 会执行一次不可逆清理：删除旧版体验档案缓存及其中登记的本地照片，然后写入 `toolbox_initialized_v1` 标记。移除快评模块后还会通过 `toolbox_quick_records_removed_v1` 标记一次性清理遗留快评缓存，不影响其余五个 `toolbox_*` 缓存。

在升级前仍需要退役的旧体验档案或快评数据时，应先使用旧版本自行留存；新工具箱只恢复旧备份中仍然存在的五类工具数据。

### 数据风险

- 卸载小程序、清理微信缓存、系统回收存储或更换设备，都可能导致本地数据丢失。
- 本地数据不会自动跨设备同步，应定期在数据设置页导出 JSON 备份，并把文件保存到小程序沙箱之外。
- 清空数据和首次升级清理均不可撤销；清空全部数据也会重置两个模拟器的本地探索统计。
- AA 导出的图片、PDF 和 JSON 可能包含金额、成员及支出信息，分享前请确认导出模式和接收人。
- 完全离线表示业务数据不上传；微信自身的文件选择、预览和分享行为仍受微信客户端能力与权限控制。

## 开发与验证

### 环境

- Node.js 与 npm：只用于开发检查和测试。
- 微信开发者工具：用于真实小程序编译和模拟器交互。
- 微信官方 `wechatide-skill`：用于打开项目、编译、页面自动化、截图和运行时诊断。
- 小程序没有运行时 npm 依赖，不需要执行“构建 npm”。

项目调测只使用微信开发者工具导出的官方 `wechatide-skill`，不依赖仓库内自定义 Agent 桥接文件。首次使用或更新 IDE 后，应动态读取本地 `skill.yaml` 并完成版本、登录与授权检查；出现 `agent_behind` 时，从状态结果返回的 `skillPath` 向 Agent Skill 目录单向整目录同步，禁止把版本号写死或反向修改 IDE 安装目录。

首次安装开发依赖：

```bash
npm install
```

运行完整校验：

```bash
npm run verify
```

该命令依次执行：

```bash
npm run check:syntax
npm run check:routes
npm run check:bundle
npm run check:guide
npm test
```

帮助内容调整后，可先生成仓库内用户手册：

```bash
npm run docs:generate
```
